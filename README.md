## 什么样的线路才算“回国优化”

商家口中的“优化线路”分三档，差距直接体现在晚高峰的大陆访问质量上。

第一档是普通国际线路。搬瓦工的KVM常规套餐走ChinaNet（AS4134）这类常规线路，晚高峰从国内访问容易拥堵，所以年付能压到49.99美元——便宜有便宜的原因，适合“能访问就行”的场景。

第二档是CN2 GT。回程走AS4809的GT段，比纯普通线路好一点，但2019年之后这条线路也开始拥堵，实际体验和普通线路拉不开明显差距。搬瓦工的CN2特惠系列基本属于这一档。

第三档是CN2 GIA。电信走AS4809双向直连，搬瓦工的GIA-E系列在此之上还接入了移动CMIN2（AS58807）和联通优质线路（AS10099），做到三网优化。官方知识库对这条线路的描述很直白：CN2 GIA是传输中国方向数据最贵的方式，但也是他们多年观察中问题最少、最稳定的网络，视频会议、VOIP这类对丢包敏感的应用就该用它。这个“贵”有实据——官方提到这条线路的IP transit成本可达每Mbps 120美元。

一句话判断标准：套餐页面没写CN2 GIA的，默认按普通线路对待。

## 香港CN2 GIA适合谁，不适合谁

适合的情况很具体：访客或用户主要在华南，跑的是实时通讯、交易撮合、游戏联机这类对延迟和抖动敏感的业务，并且能接受每月几百元人民币起步的固定成本。香港机房挂在Equinix HK2，互联对象包括Equinix IX、Google、Cloudflare、NTT和中国移动，线路底子确实是顶配。
